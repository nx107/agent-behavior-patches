# `verify-before-claim` fixture package

This directory is a complete, deterministic demo patch:

- `patch.yaml` declares metadata and the fixed verifier contract.
- `PATCH.md` contains the normative behavior instructions and limitations.
- `cases.yaml` pairs baseline and patched traces with expected outcomes.
- `fixtures/` contains synthetic event logs only.
- `results/demo-result.json` is reproducibly generated by the fixture runner.

The trusted verifier always treats both `success` and `verified` as success-bearing statuses; patch metadata cannot weaken that set. A claim needs one uniquely started command, one unique successful result, and a preceding `task_snapshot` for the same revision.

Run from the repository root:

```sh
pnpm build
node dist/cli.js validate patches/verify-before-claim
node dist/cli.js test patches/verify-before-claim --output patches/verify-before-claim/results/demo-result.json
```

`--output` accepts only a direct `.json` child of this patch's `results/` directory. The result is a **fixture/demo result**, not a benchmark and not evidence about any model provider.
